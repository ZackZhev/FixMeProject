# FixME - Профессиональный сервис авторемонта

Современный лендинг для автосервиса премиум-уровня с функцией онлайн-заявок.

## Особенности

- ⚡ Быстрая загрузка благодаря Vite
- 🎨 Современный дизайн с Tailwind CSS
- 📱 Полностью адаптивная верстка
- 🖼️ Интерактивные Before/After слайдеры
- 💬 Карусель отзывов
- 📝 Форма заявок на сервис

## Технологии

- React 18
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## Установка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен сборки
npm run preview
```

## Структура проекта

```
fixme-landing/
├── src/
│   ├── App.jsx          # Основной компонент лендинга
│   └── main.jsx         # Точка входа
├── index.html           # HTML шаблон
├── package.json         # Зависимости проекта
├── vite.config.js       # Конфигурация Vite
└── tailwind.config.js   # Конфигурация Tailwind
```
